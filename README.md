# LoopTimer
Create, chain, group, and loop sequential interval configurations.

A timer application where you can set multiple timers and loop through the timers. 

## Features

- **Multiple standalone timers** Create multiple standalone timers that can be restarted, resused and grouped.
- **Multiple groups** Create multiple groups by adding standalone timer. Each group can be restarted, reused.

## Usage
Useful for recurring tasks and reminders.
You can use this for workouts, pomodoro, reminders such as drink water, move around, have medicines etc.


It is a website and does not require any app to be downloaded. It is free to use and does not store any personal data.

Available at https://s-sinha9.github.io/looptimer/
